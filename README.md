# 여행의 페이지 — A Personal Atlas

여행 기록, 세계지도, 다음 여행지 추천을 한곳에 모은 개인 여행 홈페이지입니다. HTML, CSS, JavaScript만 사용하며 설치, 빌드, API 키 없이 작동합니다.

## Windows에서 열기

1. 바탕화면 `261001` 폴더를 엽니다.
2. `index.html` 또는 `start.bat`을 더블클릭합니다.
3. Edge 또는 Chrome에서 사용합니다. 인터넷 없이도 기본 이미지, 지도, 기록 기능이 작동합니다. 공식 관광 사이트 링크는 인터넷이 필요합니다.

Node.js가 있다면 터미널에서 `npm start` 후 `http://127.0.0.1:4173`으로 열 수도 있습니다. 패키지 설치는 필요하지 않습니다. 파일 직접 열기와 로컬 서버는 저장 위치가 다르므로 전환 전에 기록을 내보내세요.

## 사용 방법

- **여행 기록**: 전체/유럽/아시아/그 외 필터, 이름·국가·키워드 검색. 처음 4개를 보여주며 나머지 기록을 펼칠 수 있습니다.
- **기록 상세**: 날짜, 메모, 본인 사진을 입력한 뒤 `기록 저장`. 사진은 최대 1200px로 줄여 저장합니다.
- **새 여행지**: `여행 기록 추가`에서 입력. 위도와 경도를 함께 넣으면 지도에도 표시됩니다.
- **세계지도**: 세계/유럽/아시아 범위 전환. 지도 위 점이나 옆 목록을 누르면 기록이 열립니다.
- **루트 편집**: 포함할 여행지를 체크하고 위/아래 버튼으로 순서를 정합니다. 체크하지 않은 방문지도 지도 위 점으로 남으며 연결선에서만 제외됩니다.
- **다음 여행**: 자연/도시 취향 필터, 추천 이유, 일정 제안, 공식 관광 정보. 하트로 찜할 수 있습니다.
- **백업**: 화면 아래 `기록 내보내기`로 JSON을 저장하고 `기록 불러오기`로 복원합니다. 복원은 현재 브라우저 기록 전체를 교체합니다.

## 처음 들어 있는 정보

방문지 12개: 런던, 파리, 안시, 남프랑스, 이탈리아, 스위스, 오스트리아, 크로아티아, 중국, 태국, 일본, 대만.

10개 국가·지역, 유럽/아시아 2개 대륙으로 정리했습니다. 구체적인 방문 날짜, 실제 이동 순서, 개인 경험은 제공되지 않아 지어내지 않았습니다. 기본 연결선은 **예시 루트**이며, 루트를 저장하면 **나의 루트**로 표시됩니다. 국가·지역으로 주어진 여행지는 대표 도시 좌표를 사용합니다. 남프랑스는 니스, 이탈리아는 로마, 스위스는 인터라켄, 오스트리아는 빈, 크로아티아는 두브로브니크, 중국은 베이징, 태국은 방콕, 일본은 도쿄, 대만은 타이베이입니다.

추천 여행지는 포르투갈, 슬로베니아, 노르웨이, 뉴질랜드입니다. 방문 목록을 참고한 고정 에디터 추천이며 AI 실시간 추천이나 예약 기능은 아닙니다. 기간·계절은 일정 제안이고, 상세에 공식 관광청 링크가 있습니다. 이미지는 개인 여행 사진이 아닌 여행 분위기를 표현한 창작 일러스트입니다.

## GitHub에 올리기 / GitHub Pages

이 폴더의 파일과 `assets`, `scripts` 폴더를 함께 새 GitHub 저장소에 업로드하세요. 공개 사이트에는 개인 메모와 사진을 저장하는 서버가 없습니다.

Git을 사용하는 경우 이 폴더에서 PowerShell을 열고 실행합니다:

```powershell
git init
git add .
git commit -m "Create personal travel journal website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

주소의 `YOUR_USERNAME`, `YOUR_REPOSITORY`는 본인 저장소로 바꾸세요. 저장소의 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 선택하면 정적 사이트로 배포할 수 있습니다. 모든 경로는 상대 경로이므로 프로젝트 하위 주소에서도 동작합니다. 이 작업에서는 원격 저장소 생성·업로드·공개 배포는 하지 않았습니다.

## 저장 범위

기록은 해당 브라우저·해당 사이트 주소의 `localStorage`에 저장됩니다. 다른 사람·브라우저·기기와 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하거나 파일을 이동할 경우 기록 접근이 달라질 수 있으므로 JSON 백업을 보관하세요. 사진이 많아 저장 공간이 부족하면 저장 오류를 표시하고 기존 저장본을 유지합니다. GitHub에 코드만 올려서는 브라우저 메모가 공유되지 않습니다. 개인 백업 파일은 `.gitignore`로 제외했습니다.

## 파일 안내

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 구조, 입력 양식, 대화상자 |
| `styles.css` | 반응형 디자인, 모바일, 접근성 |
| `data.js` | 기본 방문지와 추천지 |
| `app.js` | 검색, 저장, 지도, 루트, 백업 |
| `assets/` | 로컬 이미지·SVG·지도 데이터 |
| `scripts/build-assets.cjs` | 지도 경로와 SVG 엽서 재생성 |
| `server.cjs` | 선택 사항인 로컬 미리보기 서버 |
| `CREDITS.md` | 참고 디자인, 데이터 출처, 이미지 생성 프롬프트 |

검사: `npm run check`. SVG와 지도 경로를 다시 만들려면 `npm run build:assets`. 완성된 자산이 포함되어 있어 실행 시 생성할 필요는 없습니다.
